## 2. 실행 순서 (레포 최상위 폴더에서)

```
python data/select_stations.py   # → data/selected_stations.csv  (대여소 45개 + ST-ID)
python data/filter_daily.py      # → data/raw/rental_daily_45.csv (45개 × 날짜별 합계)
python data/make_dbinsert.py     # → sql/dbinsert.sql
```
필요: Python 3, pandas, openpyxl (`pip install pandas openpyxl`)

## 3. 정제 규칙

- **대여소 선정**: 9개 구, 2024년 12개월 모두 기록 있는 대여소 중 연간 대여건수 상위2·중간1·하위2. 영등포 중간 자리는 양화한강공원(227)으로 교체
- **ST-ID 매칭**: 마스터 정보에서 좌표가 가장 가까운 대여소 (45개 중 41개 거리 0m, 최대 36m). 5분 단위 승객수 데이터의 이용시간·거리와 대조해 확인함
- **rental_daily**: 성별·연령대·대여구분으로 쪼개진 행을 (대여일자, 대여소번호)로 SUM. 이용 0건인 날은 원본에 없어서 0으로 채움 (45 × 366 = 16,470행)
- **weather**: 일강수량·강수 계속시간·3시간 신적설 합계·일 최심적설 빈칸 = 0, 나머지 빈칸은 NULL
- **데이터 한계**: 1월만 일별 합계가 월별 파일보다 약 7% 많음 (원본끼리 집계 차이, 2~12월은 거의 일치)
